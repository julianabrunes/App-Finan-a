# Finanças — arquivos acessíveis da página publicada

Este pacote contém a página HTML capturada e os recursos do mesmo domínio que estavam referenciados no HTML publicado em 10 de setembro de 2026.

## Limitações

Este não é o projeto-fonte original: os bundles JavaScript e CSS permanecem compilados/minificados, dados locais do navegador e serviços de backend não são incluídos, e recursos externos de terceiros não foram copiados.

Para visualizar localmente, sirva esta pasta por HTTP, por exemplo: `python3 -m http.server 8000`.
